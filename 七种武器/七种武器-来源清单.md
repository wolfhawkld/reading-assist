# 《七种武器》来源清单

## 一、定级与理由

**定级：C。**

古龙（1938-06-07 至 1985-09-21）于 1985 年去世。中国大陆与台湾地区的著作权保护期均为作者死后 50 年，即 **2036-01-01** 才进入公有领域。本报告写作时（2026-11）不存在可合法获取的全文。

因此：

- **原文引句 0 条**，「原书」档 0 条。
- **「作者谈话」档 0 条**——「七个不平凡的人，七种不可思议的武器」一类自述、以及「拳头不是武器」的否认，均见于二手转述。
- 定位只到「第几部」与「情节段」，**不给页码**。
- ★ 每部结尾「点明主题」的那句话是本系列最重要的装置，本报告只能写「大意是……」，**不引原句**。

## 三、版本与归属的分歧（一律并列，不裁断）

1. **部目**：六部为长生剑（笑）／孔雀翎（信心）／碧玉刀（诚实）／多情环（仇恨）／霸王枪（勇气）／离别钩（戒骄）。★ 主题表述各家略有出入，「戒骄」亦作「骄傲」「相聚」，本报告按通行说法并在正文注明出入。
2. **第七部四说**：① 《拳头》（又名《愤怒的小马》）——最流行，作者否认「拳头是武器」；② 《英雄无泪》的一口箱子——丁情转述；③ 本只打算写六部，「七」是出版噱头；④ 根本没有第七部。
   - ★ 第 ② 说的**反证**：《英雄无泪》全书没有青龙会，与系列主线脱节。
   - ★ 四说各有弱点，**本报告不选**。
3. **《武林七灵》**：1974 年 2 月南琪合刊，收入《七杀手》——这是「七」这个数字从出版环节被凑的最早证据。
4. **年代**：《多情环》多数记 1974，另有 1975 年初之说；《霸王枪》1975，月份未核；《离别钩》1978，月份未核。

## 四、没有使用、也不建议使用的来源

- **网络盗版全文与「七种武器全集」**：多数把《拳头》直接排作第七种而不作任何说明，读者会在不知情的情况下把凑数本当原作。
- **影视改编**：2023 年腾讯动漫与稻草熊的改编沿用「第七部为《英雄无泪》」的设定，属于创作选择，不是考据结论。
- **未署名帖文**：对第七部的「揭秘」类文章普遍把某一说当定论，本报告未采信。
