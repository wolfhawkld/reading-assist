## 《理想国》

- **作者**：柏拉图（Πλάτων / Plato，约前 427–前 347）。雅典贵族出身，苏格拉底的学生、亚里士多德的老师；约前 387 年创办学园（Academy），执教四十年
- **原名**：Πολιτεία（拉丁转写 *Respublica* / *Republic*）；★ 又译《国家篇》《共和国》《王制》——**同一个书名在中文里有七八种译法，搜书时别只看名字**
- **成书年代**：**约公元前 375 年**（学界通说在前 390–前 370 之间，各家口径不一）
- **★ 公版原文（本报告的底本）**：**Perseus 数字图书馆在 GitHub 上的官方校勘本仓库** —— ① 希腊原文（文本号 `tlg0059.tlg030.perseus-grc2`，**John Burnet 校勘本**，牛津古典丛书 *Platonis Opera* Tomus IV，1905）；② **Paul Shorey 的 Loeb 英译全文**（`tlg0059.tlg030.perseus-eng2`，Loeb 1935–37）。★ **两份文本都带 Stephanus 分节里程碑，希腊文与英译可逐节对齐**；第三层用 Project Gutenberg 的 **Jowett 英译**（#1497）作措辞对照。另有 Perseus Hopper 的 `xmlchunk` 端点持续 503、Scaife CTS API 不可达——**报告没有把取不到正文的页面冒充成读到了**，改用同源官方 XML 并写明替代路径
- **中译（★ 锚定版）**：**郭斌和、张竹明 译**，商务印书馆「汉译世界学术名著丛书」。1986-01 初版 448 页，ISBN 9787100017565；2017／2018 精装 457–458 页，ISBN 978-7-100-12966-4；2019 平装 458 页，ISBN 9787100162586。译者：郭斌和（1900–1987，江苏江阴，语文学家）；张竹明（1932– ，古希腊罗马文化专家）
- **其他中译**：王扬 译（华夏出版社，注释较详）；另有据英译转译的旧译本（不推荐）
- **篇幅**：**10 卷**；全篇按学界通用的 **Stephanus 页码**标注，起于 **327a**、讫于 **621d**；中译约 30–40 万字

- **结构**：正文 **10 卷** ＋ 附录；下部逐卷 10 节（编号 6–15，逐卷对应）；上部含一句话定位／全书骨架（10 卷一行一条）／核心论点／阅读建议／中文译本怎么选／**流行说法 vs 原文（13 条）**／争议与局限（5.1–5.7）；附录 A–D（D 8 条）
- **核验级别**：**A（公版原文，Stephanus 页码可定位）**。★ 依据为 Perseus 希腊原文 `tlg0059.tlg030.perseus-grc2`（Burnet 1905）与 Shorey 勒伯英译 `perseus-eng2`（1935–37）。**10 卷全部达 A，无一卷退到 B**。★ **辖区三条限制（须同时说清）**：① 逐字核对的是**约 80 余处关键引文**，不是逐行通读全篇；② 页面上的**中文引文是据原文自译**，不是商务版照抄；③ **（版本学事实）**郭张版各印次是否都印 Stephanus 边码、商务版页数三口径、成书年代 —— 这些**如实标了 B/C**，未擅自裁决
- **备注**：
  ① ★★ **「高贵的谎言」确有原文依据，但被读过火了**：原文是**卷三 414b–c「在需要时可以说的谎言」**，而同卷 **382c 明确说真谎（对灵魂撒谎）为神人共憎**，药用谎言仅统治者可用 ⇒ 它是**有严格条件的例外**，不是「撒谎治国」
  ② ★★ **洞穴比喻的落点是「返回的义务」**（卷七 519c–520a：法律「关心的不是某阶层的特殊幸福，而是整个城邦」）；**517a「他们难道不会杀掉他吗」是柏拉图对苏格拉底之死的直接影射** ⇒ 它**不是媒体操控的寓言**
  ③ ★ **「共产共妻」三处原文事实**（卷五 457c–464a、459d–461c）：只施于**护卫者阶层**；「共妻」是**取消私人婚姻＋城邦安排优生**（**与「性自由」正相反**）；被**亚里士多德《政治学》第二卷 1261a／1263b 逐句反驳**
  ④ ★ **「天上的范型」一句（卷十 592a–b）是「《理想国》不是政治蓝图」论的文本支柱**，与**《法律篇》的「次优、法治、无哲人王」**构成硬对照
  ⑤ ★ **厄尔神话与卷二格劳孔的规则相冲突**：格劳孔明令「不要用后果劝人正义」，而厄尔神话正是用**来世奖罚**收尾 —— 全书最诚实的自相矛盾之一（Proclus 曾专作长评）
  ⑥ ★ **`【作者谈话】` 档在本报告的实际用法**：柏拉图已逝（约前 347）⇒ 该档**改用于柏拉图本人其他文字中的自述**（主要是 **《第七封信》** 的西西里政治经历自白与 **《法律篇》** 的晚年自我修正）。**这不是访谈，报告绝不假装柏拉图能接受访谈**
- **待核实**：★ D1 成书年代（只到「约前 375」，无公认确考）；D2 中文旧译本的具体底本与版本信息；D3 郭张版「正文旁标 Stephanus 页码」的**版次差异**（各印次是否都印边码，仅有二手依据）；D4「三个浪头」的编号与卷五／卷六的边界；D5 厄尔神话是「结尾」还是「后加」（无定论）；D6「柏拉图数」（546b–c）的含义 —— **报告不给出任何数值**；D7 主动排除的来源；D8 `【作者谈话】` 档口径说明。★ 另：波普尔《开放社会及其敌人》**原书正文未取得**，其立场经学术评述**转引**
