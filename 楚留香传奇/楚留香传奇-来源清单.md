# 《楚留香传奇》来源清单

## 一、定级与理由

**定级：C。**

古龙（1938-06-07 至 1985-09-21）于 1985 年去世。中国大陆与台湾地区的著作权保护期均为作者死后 50 年，即 **2036-01-01** 才进入公有领域。本报告写作时（2026-11）不存在可合法获取的全文。

因此：

- **原文引句 0 条**，「原书」档 0 条。
- **「作者谈话」档 0 条**——古龙谈楚留香的自述（「只写过八篇」「观众只知郑少秋」）确实流传，但均为二手转述，未取得一手访谈文本，不拿转述冒充。
- 定位只到「第几部」与「情节段」，**不给页码**（这个系列本身也无可依据的唯一版式）。
- **影视剧台词不作为小说原文**。1979 年 TVB 版与 1982 年中视版的改动，正文 `## 14` 逐条划界。

## 二、实际使用的来源

| 类型 | 具体来源 | 用途 |
|---|---|---|

## 三、版本与年代的分歧（一律并列，不裁断）

1. **《新月传奇》年代**：1979 说 ／ 1978 汉麟出版说。
2. **《午夜兰花》年代**：1979 汉麟出版说 ／ 1982-09-16 至 1983-03-26《中国时报》连载 175 集说。
3. **《侠名留香》合并出版时间**：1968 说 ／ 1969 年 11 月说。
4. **「九十九章、近九十六万言」**：出自叶洪生，指《铁血传奇》整本合集，**不是单部**。口径是否含后加篇目未明。
5. **「五部曲」与「新传五部」重叠**：《蝙蝠传奇》《桃花传奇》在两套分法里都出现 ⇒ 边界不唯一，本报告按「并存」处理，不选一套。
6. **六个书名**：铁血传奇／侠名留香／风流盗帅／楚留香传奇／楚留香传奇续集／楚留香新传，各有其出版主体与年份，不存在「正确书名」。

## 四、没有使用、也不建议使用的来源

- **网络盗版全文与电子书站的「全集」**：来源不明、篇目拼凑，常把伪作（如所谓「第九篇」）混入。古龙本人已声明只写过八篇，超出者即为冒名。
- **影视剧剧情梗概**：与小说情节不一致处极多（苏蓉蓉之死、弹指神功、沈珊姑改名沈慧珊），不可作为小说内容依据。
- **未署名的读者长帖**：部目与年代错误率高，本报告未采信。

## 五、待核实项（与正文附录 C 的 D1–D10 一致）

D1《新月传奇》确切创作年／D2《午夜兰花》确切创作年／D3《侠名留香》合并出版时间／D4「九十九章、九十六万言」统计口径／D5《借尸还魂》两个别名的使用范围／D6《蝙蝠传奇》连载期号起止／D7「只写过八篇」自述的最早出处／D8 1979 版香港收视 77% 的统计口径／D9 中视 70% 与「港剧限播令」的正式名称／D10「观众只知郑少秋」一语的原始场合。

★ 其中 **D1 与 D2 最要紧**：这两部是「系列把主角写没」的关键证据，如果年代整体后移（1982–83 而非 1978–79），那么「主角被稀释」的过程就发生在影视成功之后，因果顺序要重写。本报告在正文 `## 12`、`## 13` 都保留了这一保留。
