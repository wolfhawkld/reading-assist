# 《流星·蝴蝶·剑》来源清单

## 一、定级与理由

**定级：C。**

古龙（1938-06-07 至 1985-09-21）于 1985 年去世。中国大陆与台湾地区的著作权保护期均为作者死后 50 年，即 **2036-01-01** 才进入公有领域。本报告写作时（2026-11）不存在可合法获取的全文。

因此：

- **原文引句 0 条**，「原书」档 0 条。
- **「作者谈话」档 0 条**——古龙为本书辩护「模仿绝不是抄袭」的自述确实存在，但见于二手转引，非一手访谈 ⇒ 一律按**转述**处理。
- 定位只到「第几部」与「情节段」，**不给页码、不给章号**。
- ★ 本书**章题是连载时编辑一期一期拟的**（见三·3），章号与章题都不可靠 ⇒ 全书不用章号定位。

## 三、版本与归属的分歧（一律并列，不裁断）

1. **章数两说**：春秋本 **45 章**／今通行本 **34 章**。并合的具置不详，列为 D2。
2. **分部存亡四层**（本报告最硬的一段材料）：① 《武侠世界》连载时每部首末都有分部标注；② 武林本（1971-03，3 册）未注明分部，但三册各对应一部，第一、二册末分别以「欲知后事如何，请看第二集『蝴蝶』篇」「本篇完，请看下集『剑』篇」提示；③ 春秋本**只在开篇注明「第一部 流星」**，后面的分部无踪；④ 华新／桂冠本（1977-03 修订）**一点痕迹都没有**。
   - ★ 判断：**这个结构是被版本一层层抹掉的。** 后果是「流星→蝴蝶→剑」从结构降格为标题装饰。
3. **章题是编辑的产物**：连载时每期由编辑拟旧式七字题（前六期：「终生只有杀人路」「一言判曲直 铁腕掌存亡」「枭雄恃力大 霸主逞阴谋」「仿是蓬莱谪降仙」「为防被杀唯有杀」「血腥冲鼻泪长流」）；之后插入新式标题（「死的面目」「斗智」）与（一）（二）（三）小节号，**三种并存**；武林本统一成七字并去掉小节号；春秋本前八章另拟一套七字，与武林本**不尽相同**（前五章：「终生只有杀人路」「私心怎可断曲直」「江湖道义今安在」「锄强扶弱真英豪」「英勇果敢真豪杰」）。
4. **页数两说**：河南文艺 2013 版 **483 页**／**479 页**。对应印次差别未核，列为 D8。
5. **与《教父》的关系**：古龙自己承认借鉴，并给出辩护。★ 本报告的判断：《教父》给的是**骨架**（家族／军师／叛徒／清洗），古龙加的是**第二条线**——高老大与快活林。**只有老伯一条线，这是改编；两条线一交叉，才是他自己的书。**
6. **「第一部采用分部式结构」**：本书是古龙第一部，后续沿用者有《边城浪子》《天涯·明月·刀》《三少爷的剑》。此说多源一致，但「第一部」的判定依赖创作年表，年表本身各家有出入 ⇒ 正文按转述处理。

## 四、没有使用、也不建议使用的来源

- **网络盗版全文**：本书版本链最长（连载→武林→春秋→桂冠→今传本），盗版文本无法判断属哪一环，而**分部信息恰恰是在这条链上丢掉的**。用它做分部讨论等于用结果掩盖过程。
- **把「借鉴《教父》」说成「抄袭」或反过来完全洗白的两种评论**：前者忽略第二条线，后者忽略开篇几乎是原版复刻的事实。本报告两头都写。
- **影视剧情当小说情节**：1976 邵氏版由倪匡编剧、楚原修改，加入了原著中分散的线索并重排；把电影当原著写是硬错。
- **未署名帖文对高老大身世的渲染**：那几段情色描写在讨论中常被单独摘出传播，脱离人物语境后既失真也低俗。本报告只作结构性引用，不复述细节。

## 五、待核实项（与正文附录 C 的 D1–D10 一致）

D1《武侠世界》601–638 期与武林本三册的对应关系／D2 45 章与 34 章的并合位置／D3 春秋本前八章七字题的拟者／D4 华新／桂冠本 1977 修订的实际改动范围／D5《教父》中译本的流通时间与本书写作先后／D6「老伯就是教父的影子」自述的原始出处／D7 高老大复仇段在不同本子里的文字差异／D8 483 页与 479 页对应的印次差别／D9 1976 年邵氏电影补拍镜头的数量与内容／D10 连载原刊上的分部标注是什么形态。

★ 其中 **D1、D4、D10 管分部这条主线**，D2、D3 管章数章题，D5、D6 管《教父》。★ D10 最关键：如果连载原刊的分部标注只是编者按而非作者所加，那「三部结构」的作者归属就要重新讨论。本报告按「原设计」处理，但这个前提本身待核。
