# 《萧十一郎》（两部）来源清单

## 一、定级与理由

**定级：C。**

古龙（1938-06-07 至 1985-09-21）于 1985 年去世。中国大陆与台湾地区的著作权保护期均为作者死后 50 年，即 **2036-01-01** 才进入公有领域。本报告写作时（2026-11）不存在可合法获取的全文。

因此：

- **原文引句 0 条**，「原书」档 0 条。
- **「作者谈话」档 0 条**——古龙确实为本书写过序（《写在〈萧十一郎〉之前》），但本报告未核到原始刊本，且无可靠一手访谈文本 ⇒ 序文内容一律按**转述**处理，不冒充「作者谈话」。
- 定位只到「第几部」与「情节段」，**不给页码、不给章号**。
- ★ 本书**章号不是作者分的**（见三·3），因此全书不用章号定位。

## 三、版本与归属的分歧（一律并列，不裁断）

1. **春秋本的册数**：**14 册**／亦著录为 **14 章**／亦著录为 **14 辑**。★ 三说并列。分歧来自「册」「章」「辑」三个单位在这套书里被混用，本报告不裁断哪个对，只注明三者指的是同一个初始形态。
2. **汉麟本的底本**：一说「以南琪为底本」，一说「标题均采自春秋本」。★ 两说并存，本报告并列，列为 D2。
3. **25 章不是古龙分的**：据《台湾武侠小说发展史》，汉麟 1977 年改版时，《萧十一郎》的分章出自古龙好友、汉麟老板**于志宏**之手，为顺应读者阅读习惯、**征求古龙同意**后重排。★ 这是本书最硬的一条版本事实：**「第几章」是出版社老板分的。**
4. **先有剧本还是先有小说**：三层并列——① 工序事实：1969 年为徐增宏写剧本 → 1970 邵氏拍成 → 1970 小说连载结集，**剧本在先无争议**；② 作者自述：先有剧本、电影开拍前才有小说，所以小说枝节少、废话少；③ 相反说法：电影其实由小说改编，因为故事在他心里酝酿很久，「他要写的本来就是小说」。
   - ★ 本报告的判断：**三层不真冲突，冲突的是「哪个算数」。** 物理顺序上剧本在前；但「先写剧本」不等于「为电影而写」。
5. **一稿两投之说**：南琪本与武侠春秋本在回目、标点、字句上均有差异，有考据者推测是作者同时投给两家。★ **推测而非定论**，列为 D3。
6. **叶洪生的评价**：「《萧十一郎》是糅合新旧思想，反讽社会现实，讴歌至情至性，鼓舞生命意志的一部超卓杰作」，并将其抬到古龙作品第一的位置。★ 这是**一家之评**，且叶洪生是台湾武侠评论界的权威，本报告照录并标明是评价不是事实。

## 四、没有使用、也不建议使用的来源

- **网络盗版全文**：本书至少五套版本、章数从 14 到 54 到 25 不等，盗版文本无从判断属哪一套，用它做「第几章如何」的引述等于把版本问题掩盖掉。
- **影视剧情当小说情节**：多数改编让萧十一郎与沈璧君最终走到一起，**原著并未交代**。把剧版结局当原著结局，是这本书最常见的误读。
- **把「先有剧本」当质量保证的评论**：工序只影响枝节多少，不影响好坏。这类说法是读者的一厢情愿。
- **未见剧本却断言剧本留下了什么**：本报告核不到剧本，凡涉剧本与小说的实际差异一律列为待核（D4）。

## 五、待核实项（与正文附录 C 的 D1–D10 一致）

D1 春秋本「14 册／14 章／14 辑」三种著录的原始出处／D2 汉麟本据南琪还是据春秋／D3「一稿两投」能否成立／D4 剧本与小说的实际差异／D5 序的原始刊本与两个标题的改换经过／D6 于志宏重排 25 章的具体依据／D7 南琪本与武侠春秋本文字差异的完整清单／D8《火并》连载的起止期号与南琪本出版时间的关系／D9 司徒中平这条线在连载本里是否有残留／D10 各版本册数与章数的完整著录。

★ 其中 **D4、D5、D7 最要紧**：它们分别对应三件事——剧本到底留下了什么、序到底什么时候从「之后」变成「之前」、两个本子的文字差多少。三件都指向同一个问题：**这本书的「原始形态」到底该以哪一版为准。**
