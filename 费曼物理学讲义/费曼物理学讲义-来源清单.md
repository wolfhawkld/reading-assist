## 三、核验级别判定

**分级定义（本项目通用）**

| 级别 | 含义 |
| --- | --- |
| **A（全文核验）** | 有**版权方官方发布的免费全文**，正文可逐章（甚至逐节）定位 |
| B（带页码引文） | 无全文，但有带页码的合法引文／书评可核 |
| C（二手转引） | 无全文，事实只能取自出版方与图书馆编目的转录 |
| D（不足） | 仅有个别网页，无法交叉验证 |

**本书为何落在 A 级**

- `【原书】` **版权方 Caltech 与 Basic Books 官方发布的三卷全文在线阅读**（feynmanlectures.caltech.edu）是本项目「合法一手全文」的最强形态之一。
  它由版权方授权、注明版权（© 1963–1965, 2006, 2013 Caltech / Gottlieb / Pfeiffer），**三卷正文完整可读**。
- 卷 I 的**逐章章名、章节结构、序言原话**，我都能**逐条点开核对**（如《费曼自序》位于 I_91.html）。
  ⇒ 「这本书里某句话说了什么」在本页是**可定位**的，这是 A 级的判据。

**但必须写清「辖区」（核验到什么程度）**

1. **本页详核的是卷一。** 卷二、卷三虽同样在线可读，但本页**未逐模块展开**，只给出卷级说明与几处关键章节。
2. **「在线版＝印刷版」有边界**：在线版是新千年版（2011）文本，**不标印刷页码**；
   因此本页**不写页码**（也无需写——章号＋节号足以定位）。印刷版页码需查相应复本版权页。
3. **结构／版本／序言 = A 级一手**；**模块划分／路线／必读判断 = `【推断】`**，一个来源都没有。
4. **中译版的页数、旧版 ISBN** 属 **C 级（二手转引）**，见附录 D。

★ 一句话：**本书的「原文核验」是 A 级（卷一逐章可定位），但「怎么读这套书」的建议是我的整理，不是原书内容。**

## 四、检索盲区

1. **⚠ 在线版无页码。** 官方在线版按「章—节」组织（如 §37-1），**不含印刷页码**。
   ⇒ 本页章节地图**只有章号与章名，没有页码**。这不是遗漏，是官方在线形态使然。
2. **英文各卷的印刷页数未取得可靠一手数据。** 出版方与在线版均不标总页数；我未找到一致口径，故**不写**。
3. **中文旧版（1980 年代／2005 年版）的书目细节未核实。** 见「附录 D2」。
   「上海科技自 1982／1983 年起引进」的说法只见于百科镜像页，**无法当作独立来源**。
4. **《补编》与《习题集》中文版的页数／ISBN 未逐一与出版方比对。** 部分细节来自百科与电商页。
5. **二、三卷的逐模块「必读／可跳」判断未做**（本页范围只锚定卷一）。
6. **未见任何学术性「批评文献」。** 与叙事型书籍不同，本书被学界普遍视为经典；
   检索到的「批评」多为读者层面的「太难／太长／不适合当教材」，**没有署名、带出处的学术批评**，
   故正文 §5 未列争议（教材型契约本就不设「争议」栏，但这里如实说明：是**没有**，不是**没找**）。
7. **「分卷订正数 332／263／200」只标 `【转述】`。** 总数 885 处有官方页（`【原书】`）；
   分卷数出自《新千年版前言》，因其官方在线页本次未能渲染，我读到的是**授权平台的中文译文**，
   措辞可能有出入，故降为 `【转述】`（详见正文附录 D7）。

## 五、给读者的使用建议

1. **一手核验入口**：任何「书里到底怎么说的」问题，直接查 feynmanlectures.caltech.edu 的对应章（如
   卷 I 第 37 章 = I_37.html），这是**版权方全文**，比任何二手转述可靠。
2. **读之前先读《费曼自序》**（I_91.html）。费曼本人在里面交代了「给谁讲、讲到哪、为什么这么讲」，
   其优先级高于本页的三条路线。
3. **按路线 B（卷一最小集）开局**：第 1→2→4→5→7→8→9→10→15→16→21→37→38→44→46 章。
   走完这一串，你已经拿到了「费曼式物理图像」的完整样本。
4. **想动手就配《习题集》**；但顺序是**先读讲义建立图像，再做习题**。
5. **本页没有页码，这不是漏。** 请用官方在线版的章—节编号定位，它比印刷页码更稳定。
