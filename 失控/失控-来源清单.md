## 三、核验级别判定与辖区

**定级：A 级（逐字核对了作者授权发布的全文）**

- **依据**：`https://kk.org/outofcontrol/` 的 149 个逐章 HTML ＋ `https://kk.org/mt-files/books-mt/ooc-mf.pdf`。作者本人在自有域名发布。
- **实际做了什么**：下载 → 剥标签清洗 → 合并为 1,383,048 字符的纯文本 → 按官网目录切为 24 章 → **24 章全部读过**（第 3、10、11、12、13、14、16 章因单次读取超限而分段读，但均读完整章）。
- **覆盖到哪**：英文原书正文 24 章的全部 `【原书】` 引文；九律英文原文；全书的关键词检索（Metcalfe／Alexander／Turing／Varela／Wired／Bitcoin／World Wide Web 等）。
- **没覆盖到哪（明确降级，不冒充 A）**：
  1. **中译本** —— 未取得中译全文，版本／章号判断依据目录与编目 → **B/C 级**；
  2. **书后注释书目的原始文献** —— 我只读了 KK 写的评注，未读被引论文 → **C 级**；
  3. **批评文献原文** —— Thieme 的原文读到了；**Grassie 与 Stepney 的原文链接已失效**，只有 KK 官网列出的标题、单位、出处 → **B/C 级（见 D6）**；
  4. **KK 1994 年之后的一切表态** —— 单列 `【作者谈话】`，不冒充原书。
- **逐章降级情况**：**无**。24 章全部按 A 级处理，没有一章降级到 B 或 C。
