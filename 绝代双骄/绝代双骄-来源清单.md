# 《绝代双骄》来源清单

## 一、定级与理由

**定级：C。**

古龙（1938-06-07 至 1985-09-21）于 1985 年去世。中国大陆与台湾地区的著作权保护期均为作者死后 50 年，即 **2036-01-01** 才进入公有领域。本报告写作时（2026-11）不存在可合法获取的全文。

因此：

- **原文引句 0 条**，「原书」档 0 条。
- **「作者谈话」档 0 条**——古龙把本书归为「中期创作的最后一部」这一自我归类，见于二手著录，未见原文。
- 定位只到「第几段」与「情节段」，**不给页码、不给章号**。
- ★ 本书**章数有三说**（128／127／126），章号本身不可靠 ⇒ 全书放弃章号定位。这是本报告与先例的一处实质不同。

## 三、版本与归属的分歧（一律并列，不裁断）

1. **章数三说**：春秋本原始分章 **128 章**／大陆通行整理本 **127 章**／另一套著录 **126 章**。★ 三个数字都有本子支撑，差别来自「数的是哪一个本子」。本报告三说并列，不裁断，正文因此不用章号定位。
2. **香港连载**：一说香港《武侠与历史》1966-02 至 1969-03 连载。**与本报告的「1966 年起」不矛盾，但起止月份与台湾不同**，并列。
3. **篇幅两说**：约 **100 万字**（通行说法）／河南文艺版版权页 **1164 千字**。口径不同（是否含标点与排版），并列。
4. **分卷三说**：曹惠民称「五卷」／天地图书版 6 卷／河南文艺版 4 册。★ 这是**三种装帧，不是三种内容**。
5. **倪匡补稿**：著录说本书「曾被倪匡补了二十几天的稿子」，后由古龙亲自增修完成。★ **补稿不是代笔**：补稿是原稿中断、他人临时接手几十天、作者回来自己统稿；代笔是整段由他人续写、作者不回炉（如《圆月弯刀》后半由司马紫烟续写、《凤舞九天》由薛兴国续完）。补的是哪一段、补了多少字，**本报告核不到**，列为 D5。
6. **「中期创作最后一部」**：作者自我归类，见于二手著录，未见原文。正文按转述处理，列为 D10。

## 四、没有使用、也不建议使用的来源

- **网络盗版全文与「全集」文本**：本书章数三说、又有新旧两本，盗版文本往往来源不明，无从判断属哪一套。用它来做「第几章如何」的引述，等于把版本问题掩盖掉。
- **影视剧情当小说情节**：本书 10 个影视版本改动极大（人物合并、结局重写），把剧版当原著写是硬错。本报告凡涉影视一律标明是改编。
- **把补稿说成代笔的二手文章**：这类说法忽略「作者回来统稿」这一步，把接力读成换人，会误判全书的质量归属。
- **以「一百万字」为由推断写作质量的文章**：篇幅长是结构选择（信息差需要延迟），不是评价依据。

## 五、待核实项（与正文附录 C 的 D1–D10 一致）

D1《公论报》79 集与春秋本 64 集的换算关系／D2 香港《武侠与历史》1966-02 至 1969-03 之说／D3 128／127／126 三说的差异落在哪些章／D4 旧本与新本的具体差异／D5 倪匡补稿的位置与字数／D6 河南文艺版页数与字数的统计口径／D7 十个影视版本的完整清单／D8 曹惠民「五卷」说的依据／D9 附录 B 章次区间的粗估／D10「中期创作最后一部」自述的出处。

★ 其中 **D4 最要紧**：本书是古龙唯一一部亲手重修过的作品，如果新旧本的差异足够大，「原著如何」这个说法就必须先说明是哪一个「原著」。本报告只能确认「有新旧两套」，无法确认改了什么。
