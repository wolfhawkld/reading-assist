# 《陆小凤传奇》来源清单

## 一、定级与理由

**定级：C。**

古龙（1938-06-07 至 1985-09-21）于 1985 年去世。中国大陆与台湾地区的著作权保护期均为作者死后 50 年，即 **2036-01-01** 才进入公有领域。本报告写作时（2026-11）不存在可合法获取的全文。

因此：

- **原文引句 0 条**，「原书」档 0 条。
- **「作者谈话」档 0 条**——「拳头不是武器」这类自述、以及关于陆小凤的创作谈，均为二手转述或弟子回忆，不冒充一手引文。
- 定位只到「第几部」与「情节段」，**不给页码**。
- 「灵犀一指」「四条眉毛」作为人物标记只作中文提及，不引相关句子。

## 三、版本与分期（一律并列，不裁断）

1. **三种「非亲笔」必须分开**：① 续写——《隐形的人》断稿后由薛兴国续完并改名《凤舞九天》；② 佚文——1977 香港武林版多出 40 余页连载所无的内容，另有武功本自〈仗义救人〉一章后四十页迥异且故事未完；③ 口述——《剑神一笑》据古凌〈古龙的短刀〉「可能口述」。
2. **《剑神一笑》的性质**：1980 年古龙投资宝龙电影公司，为拍同名电影赶写，先把故事改编成剧本。**先有电影后有小说**，与「晚年水准下降」是两回事。
3. **第七部连载**：1981-07-04 至 08-07，转《南洋》连载，再次续稿未至。
4. **第五部《幽灵山庄》**：1975 年 6 月《武侠春秋》246 期目录已见，1977 年才由春秋出版成书。
5. **书名沿革**：第一部原名《陆小凤》（后称《金鹏王朝》）；第二部原名《凤凰东南飞》（后称《绣花大盗》）；第六部原名《隐形的人》（后称《凤舞九天》）。

## 四、没有使用、也不建议使用的来源

- **网络盗版全文与「全集」电子书**：来源不明，且有把《凤舞九天》与《隐形的人》混为一种、隐去续写事实的版本。
- **影视剧剧情**：1976 年以来改编极多（刘松仁、万梓良、张智霖、林峯等），情节改动大，不可作为小说依据。
- **未署名的「古龙佚文」整理帖**：1977 武林版那 40 余页的归属至今无定论，任何声称「已确证」的说法都缺依据。

## 五、待核实项（与正文附录 C 的 D1–D10 一致）

D1 香港版连载的起始日／D2 第六部断稿在第 128 期的具体回目／D3 断稿处对应的情节位置／D4 武林版四十余页的归属／D5 武功本〈仗义救人〉后四十页的来源／D6《剑神一笑》「口述」说的可靠程度／D7 转《南洋》连载的起止／D8《大游侠》117 章与今本的对应关系／D9 薛兴国接续的确切起点／D10《民生报》连载的起止。

★ 其中 **D2 与 D3 最要紧**：断稿停在哪一句、哪个情节，决定了「读者读到的高潮是不是作者设计的高潮」。本报告只能确认日期（1975-01-24）与期数（128），**不能确认断点位置**，因此正文 `## 11` 只写「断在案的收束之前」，不编具体句子。
