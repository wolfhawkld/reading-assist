## 核验级别判定（先读这一节）

### 1. 支持本级的材料

本书的整体定级是 **A（全文核验）**，依据不是「有一本书在手上」，而是**有合法、可检索、可逐字比对的法文全文**：

| 材料 | 性质 | 本报告怎么用 |
| --- | --- | --- |
| Project Gutenberg **#54873**（法文） | 公有领域全文，Distributed Proofreaders 制作，PG 页明标 `Title`／`Author`／`Illustrator` | **主底本**。全部法文引文、章题、数字、船体参数以它为准，逐条脚本核对命中 |
| Project Gutenberg **#5097**（法文） | 公有领域全文，另一独立校对 | **交叉底本**，只做异文比对，**不作引文来源** |
| Project Gutenberg **#2488**（Walter 1991 英译） | PG 页明标 `Translator: Frederick Paul Walter` | 英译引文，A 级 |
| Project Gutenberg **#164**（英译） | PG 页**未标译者** | 删节本对照，**B 级**（见下节判定） |

★ **A 级的确切含义**：本报告能逐字核对的，是**这两份 PG 电子文本**，不是 1869 年的纸书。PG 转录可能有错字、漏行。若与纸书不符，以纸书为准——**本报告未核对任何纸书**。这一点必须写明，否则「A 级」会被误读成「我读过原版」。

### 2. 为什么英译分成 A 与 B 两级

- **Walter 1991（#2488）→ A**：PG 文件头**明确标注译者**，书名作 *Twenty Thousand Leagues Under the **Seas***（复数），是公认的足本。
- **#164 → B**：PG 文件头**没有译者字段**。本报告判定它是 **Mercier 1873 译本**，但这是**判定不是声明**，依据三条内部证据（见 ①-1.3）。凡引用 #164 的地方，正文都注明了「Mercier」，并明确这是本报告的判定。

### 3. 为什么中译只能是 C

中文译本没有合法全文可用（各译本均在版权期内），本报告**没有接触过任何一本中译实物**，也无法核对任何一句译文。因此：

- 凡涉及中译，一律标 `【转述】`，**不给页码、不作逐字引用**；
- 译本谱系、译者、出版社、年份，均据公开书目信息转录；
- 有三说以上的年份争议，一律进附录 D，**不在正文里挑一个当定论**。

PG #2488（Walter 1991）的页面里带有 `*** This is a COPYRIGHTED Project Gutenberg eBook ***` 提示。这**不影响它的可用性**，但要说清楚：

- 它是 **PG 获授权发布的版权作品**，属于**合法来源**（不是盗版站的扫描件）；
- 它的合法性**来自 PG 的授权链条**，不来自「公有领域」；
- 因此本报告在引用 Walter 译文时，只作**有限引用**（短句、对照用），不整段搬运。

## ③ 中译本与版本

★ 本节**全部是 C 级**：没有合法全文，没有实物，只有公开书目信息。**不构成译本优劣评价。**

| 译本 | 常见出版信息 | 本报告的处理 |
| --- | --- | --- |
| 曾觉之 | 中国青年出版社等；首版年份有 1947／1961 两说 | 年份两说并列，进 D7 |
| 其他通行译本 | 多家出版社，具体印次未核 | 只作「存在多个中译」的说明，不列优劣 |

★ **书名的问题比译本更大**：中文通译「海底两万里」把法文 `lieue`（里格，约 4 公里）换成了中文长度单位「里」，于是 `20,000 lieues`（约 80,000 公里，绕地球两圈）变成了「两万里」（10,000 公里）＋「海底」的深度联想。**这不是某一家的误译，是通行书名层的积习**（附录 D6：本报告未做版本普查）。
