  - **★ 辖区声明**：**「局部 A」只适用于这一篇序言**；**《自私的基因》正文 15 章仍为 B 级**。**不许把本报告的「局部 A」暗示成「整本书都核对过」。**
- **A / B / C 的边界**：
  - A ＝ 逐字核对了合法全文 → **仅序言部分**；
  - B ＝ 有带章号／卷期的可定位引文，未逐字核对全文 → **全书其余部分**；
  - C ＝ 二手转引 → 报告里凡标 `【转述】` 者（如霍尔丹名言、觅母学「被许多学者视为伪科学」等）。
